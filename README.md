# hi, i'm moby

designer, tinkerer, curious by default. i turn early ideas into things people can use.

i'm a staff design engineer in london, working on an AI-native productivity product. right now i'm most interested in how people and AI agents can collaborate — not just chat, but actually make things together.

## selected work

- **[call me moby](https://github.com/mubarakmarafa/call-me-moby)** — my portfolio, as a game boy color you can play with. built with three.js and gsap. [callmemoby.dev](https://callmemoby.dev)
- **[promptly](https://github.com/mubarakmarafa/Promptly-2026)** — spotify wrapped for your prompting. an agent skill that reads your local chat history and builds a visual story you can share. made with chelsea.
- **[designloop](https://github.com/mubarakmarafa/designloop)** — an agent skill that raises the quality of an existing interface, or its writing, by measuring it, not guessing. capture → judge → fix, until it actually gets better.
- **[duo](https://github.com/mubarakmarafa/duo-studio)** — a motion-studio site, built as a single static page. [live demo](https://duo-studio-seven.vercel.app)
